# 股基论坛 - 用户使用说明

## 快速开始

### 1. 启动项目

```powershell
# 终端1 - 启动后端
cd D:\0study\vscode\workspace\course_practical\backend-test
$env:SQLITE_FALLBACK="true"; $env:AUTO_CREATE_TABLES="true"
.venv\Scripts\Activate.ps1
uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload

# 终端2 - 启动前端
cd D:\0study\vscode\workspace\course_practical\Stock-Fund-Investment-Forum
npm run dev
```

前端默认运行在 `http://localhost:5173`（或 6789）。

### 2. 注册与登录

- 点击右上角"注册"，支持邮箱或手机号注册
- 注册成功后自动登录
- 下次访问点"登录"即可

### 3. 发帖

| 帖子类型 | 入口 | 特点 |
|---|---|---|
| 普通帖子 | 首页 → 发帖 → 普通帖子 | 文字 + 图片 + 标签 + 附件 |
| 长文分析 | 首页 → 发帖 → 长文分析 | Markdown 编辑器 + 实时预览 |
| 投票调研 | 首页 → 发帖 → 投票调研 | 动态添加选项 |
| 实时讨论 | 首页 → 发帖 → 实时讨论 | 短内容无需标题 |

### 4. 互动

- **点赞**：帖子或评论旁 👍 按钮
- **收藏**：帖子底部 🔖 按钮
- **分享**：帖子底部"分享"按钮（复制链接）
- **评论**：帖子底部输入框，支持 @用户名 提及他人
- **回复评论**：点击评论的"回复"按钮，支持多级楼中楼

### 5. 关注与粉丝

- 进入任意用户主页，点击"关注"按钮
- 用户主页可查看"粉丝"和"关注"列表
- 点击用户可跳转到对方主页

### 6. 私信

两种方式发起对话：
1. 进入用户主页 → 点击"发私信"按钮
2. 访问 `/messages` → 左侧输入用户ID按回车

对话列表中点击对话查看历史消息，底部输入框发送消息。

### 7. 群组

| 功能 | 位置 | 说明 |
|---|---|---|
| 创建群组 | `/groups` → 创建群组 | 设置名称/描述/权限 |
| 加入群组 | 发现群组 → 加入 | 公开群组直接加入 |
| 群内发帖 | 群详情 → 讨论 → 输入内容发布 | 自动关联到群组 |
| 上传文件 | 群详情 → 文件 → 上传 | 仅群组成员可上传 |
| 创建投票 | 群详情 → 投票 → 创建投票 | 至少2个选项 |
| 群组设置 | 群详情 → 群组设置 | 群主/管理员可修改 |

### 8. 搜索

- 顶部导航栏搜索框，输入关键词按回车
- 或访问 `/search` 页面
- **搜索联想**：输入时下拉显示匹配结果
- **高级筛选**：时间范围/排序/板块/帖子类型/只看精华
- 支持搜索帖子、用户、股票

### 9. 个人设置

访问 `/settings`：

| Tab | 功能 |
|---|---|
| 个人资料 | 修改昵称、简介、联系方式 |
| 账号安全 | 修改密码 |
| 通知设置 | 消息通知开关 |
| 隐私设置 | 信息可见范围 |
| 投资偏好 | 关注市场、行业偏好 |
| **专业认证** | 上传从业资格/学历证明，申请加V |
| **风险评估** | 完成问卷，获取风险等级评估 |

### 10. 专业认证流程

1. Settings → 专业认证 → 选择认证类型
2. 填写说明 → 提交
3. 管理员审核通过后账号自动加V（EXPERT）
4. 已认证用户帖子旁显示黄色"V"标识

### 11. 管理后台

访问 `/admin`（需登录）：

| Tab | 功能 |
|---|---|
| 概览 | 8项统计（用户/帖子/评论/违规/今日数据等） |
| 认证 | 审核专业认证申请（通过/驳回） |
| 评估 | 审核风险评估结果 |
| 违规 | 查看和管理违规记录（确认违规/误报） |
| 用户管理 | 搜索用户、封号/禁言/解封 |
| 审计日志 | 所有操作时间线记录 |

**敏感词自动过滤**：含"荐股/稳赚/内幕消息"等敏感词的帖子/评论自动标记为违规。
