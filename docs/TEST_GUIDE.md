## 常见问题

**Q: 401 未授权错误**
A: 数据库重建后旧 token 失效，重新注册登录即可。

**Q: 后端改了代码后前端没变化**
A: 前端用 `npm run dev`（热更新），改代码后直接刷新浏览器。

**Q: 后端改了代码后没生效**
A: 使用 `--reload` 模式，但某些情况需完全重启。

**Q: Admin 页面打不开**
A: 确保已登录（ProtectedRoute 会重定向到登录页）。
